Langkah 1: Buat Akun GitHub 1. Buka situs resmi GitHub dan daftar akun baru jika Anda belum memilikinya. 2. Verifikasi email Anda dan masuk (login) ke dasbor GitHub. Langkah 2: Buat Repositori Baru 1. Di pojok kanan atas, klik ikon tanda + lalu pilih New repository. 2. Isi nama repositori (repository name) dengan format khusus: username.github.io (ganti kata username dengan nama akun GitHub Anda yang sebenarnya). 3. Pilih pengaturan visibilitas menjadi Public. 4. Klik tombol Create repository. Langkah 3: Tambahkan File Website (HTML/CSS/JS) Anda bisa mengunggah file kode website secara langsung melalui browser atau menggunakan Git di komputer: • Cara Cepat lewat Browser: 1. Di halaman repositori yang baru dibuat, klik creating a new file. 2. Beri nama file utama dengan index.html. 3. Masukkan kode dasar HTML Anda (misalnya teks "Halo, ini website pertama saya!"). 4. Gulir ke bawah dan klik tombol hijau Commit new file. • Catatan Penting: GitHub Pages hanya mendukung website statis (HTML, CSS, dan JavaScript), tidak mendukung bahasa backend seperti PHP atau database. Langkah 4: Aktifkan GitHub Pages 1. Di dalam repositori Anda, klik tab Settings (Pengaturan) di bagian atas. 2. Pada menu navigasi sebelah kiri, cari dan klik bagian Pages. 3. Pada bagian Build and deployment -> Source, ubah pilihan dari None menjadi Deploy from a branch. 4. Di bagian Branch, pilih cabang utama (biasanya main atau master) dan arahkan folder ke / (root), lalu klik Save. Langkah 5: Akses Website Anda • Tunggu sekitar 2 hingga 3 menit agar GitHub memproses situs Anda. • Refresh halaman Settings -> Pages, lalu Anda akan melihat tautan (link) live website Anda di bagian atas (biasanya beralamat di https://github.io).
